# Promo Marbre Benayache | SARL FB PROMO

Site vitrine officiel de haute performance pour **Promo Marbre Benayache** (SARL FB PROMO), usine de sciage, transformation et façonnage de marbre, granit et pierres naturelles basée à Chelghoum Laïd (Wilaya de Mila, Algérie).

## 🚀 Caractéristiques & Performance
- **Chargement ultra-rapide** : Architecture native HTML5 / Vanilla CSS / Vanilla JS (zéro dépendance externe lourde).
- **Images optimisées WebP** avec balises `<picture>` et fallback JPEG.
- **Vidéo Hero 720p HD** avec coupure automatique au scroll via `IntersectionObserver` pour préserver le GPU et la batterie.
- **Carrousels tactiles fluides** (gestes tactiles, clavier, mise en cache des calculs).
- **Modale dynamique** pour chaque variété de marbre avec devis WhatsApp personnalisé.
- **SEO local** : Balises Open Graph, Twitter Cards et données structurées Schema.org JSON-LD.
- **Design moderne & responsive** adapté aux mobiles, tablettes et écrans 4K.
